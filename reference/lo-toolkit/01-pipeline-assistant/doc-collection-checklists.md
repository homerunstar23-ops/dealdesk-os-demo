Generic, commonly requested items for **business-purpose investor loans**. The actual program guidelines and company systems always control — use these to prepare the borrower, not to replace the official conditions list. Full side-by-side matrix: `../03-underwriting-support/Document-Requirement-Matrix.xlsx`.

## Every file (all loan types)
- [ ] Company loan application / intake
- [ ] Government photo ID (each guarantor)
- [ ] Credit authorization
- [ ] Asset statements (commonly recent consecutive months) for down payment, costs, reserves
- [ ] Letter of explanation for large deposits, if any
- [ ] Entity docs if vesting in an LLC/corp: articles, operating agreement, EIN, good standing, authorized signer
- [ ] Insurance agent contact (hazard; flood if required)
- [ ] Title/escrow contact

## DSCR rental (purchase or refi)
- [ ] Purchase contract (purchase) or mortgage statement/payoff (refi)
- [ ] Lease(s) / rent roll, or plan for market-rent analysis via appraisal
- [ ] Property tax and HOA info
- [ ] Insurance quote showing dwelling coverage (and loss of rents if the program asks)
- [ ] Track record schedule (if program considers experience)
- [ ] Short-term rental: booking history/projections if the program allows STR income

## Fix & flip
- [ ] Purchase contract + addenda, assignment contract if wholesale
- [ ] Line-item scope of work and budget (use `products/files/Scope-of-Work-and-Rehab-Budget.xlsx`)
- [ ] Contractor bid, license and insurance (or owner-builder plan if allowed)
- [ ] Track record schedule (addresses, dates, purchase/sale prices)
- [ ] Exit strategy (sale timeline, comps supporting ARV)
- [ ] Draw schedule acknowledgment

## Bridge
- [ ] Purchase contract or payoff statement
- [ ] Exit plan (refinance, sale) with timeline and supporting documentation
- [ ] Property income/expense info if income-producing
- [ ] Entity and guarantor docs

## Ground-up construction
- [ ] Lot purchase contract or deed (if owned)
- [ ] Plans/specs, permits or permit status, survey
- [ ] Builder contract, license, insurance, builder resume
- [ ] Line-item construction budget and schedule
- [ ] Exit: sale comps or refinance plan
- [ ] Track record (construction experience)

## Cash-out refinance (investment property)
- [ ] Current mortgage statement(s) and payoff
- [ ] Leases / rent roll
- [ ] Proof of ownership date (seasoning) and, if recently acquired, settlement statement and rehab receipts
- [ ] Intended use of proceeds statement (supports business-purpose determination — follow company procedure)
- [ ] Insurance declarations page, tax bill, HOA info
